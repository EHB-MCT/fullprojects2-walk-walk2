# Walk Brussels

## Project Overview

Walk Brussels is a small website where people can report obstacles on the sidewalk in Brussels.
The idea is to make it easier to show what is blocking the way, add a photo, and leave extra information.

This project was made as a student project with simple HTML, CSS, and JavaScript.

## Features

- Homepage with a short introduction about making sidewalks more accessible.
- Multi-step report flow.
- Page to choose the type of obstacle.
- Photo upload field with image previews.
- Optional comment and contact form.
- Municipality dropdown that shows which email address the report would go to.
- Thank you page after submitting the form.
- Mobile navigation menu.
- Switch between color mode and black-and-white mode.
- Saves some user details in localStorage.
- French and Dutch

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- Custom fonts and image assets

## Installation

No installation is needed.

Download or clone the project and open `index.html` in a browser.

## Usage

1. Open `index.html`.
2. Click on **Meld een obstakel**.
3. Choose the obstacle type.
4. Upload one or more photos.
5. Add extra information if needed.
6. Fill in your details and choose a municipality.
7. Submit the form to go to the thank you page.
